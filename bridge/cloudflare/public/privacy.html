Privacy Notice

This service is used by VC Cli to complete OAuth logins.

What we temporarily process

  • OAuth state and PKCE metadata
  • One-time localhost callback URL and nonce
  • OAuth code exchange result for immediate localhost handoff

Retention

Pre-auth session metadata is stored in short-lived KV records and expires automatically (minutes). Access and refresh tokens are not persisted in bridge storage.

Data sharing

This service does not sell OAuth data and only uses it to complete login requests.

Questions: open an issue in the repository where this service is hosted.

Service usage terms are available at /terms.html.
